# Contributing

UniPool is maintained as a research code release. Contributions should focus on
the UniPool expert-pool implementation, reproduction scripts, documentation, and
small compatibility fixes needed to keep the release usable.

Before submitting a change, run the lightweight checks from
[CONTRIBUTING.md](../../CONTRIBUTING.md). Full Megatron tests require the GPU
training dependency stack.

Preserve upstream Megatron copyright and license notices when editing files that
originated from Megatron-LM.
